# simu — 브라우저 MJCF 로봇 시뮬레이터

https://seonghyeonornot.github.io/simu/

MJCF(XML + 메쉬) zip을 올리면 브라우저 안에서 MuJoCo 물리로 로봇을 돌려 보는 웹 도구입니다. 서버 없이 동작하고, 올린 파일은 브라우저 밖으로 나가지 않습니다.

## 실행

- **GitHub Pages**: 저장소 Settings → Pages에서 `main` 브랜치 `/ (root)`를 켜면 `https://<계정>.github.io/simu/`로 열립니다. (비공개 저장소의 Pages는 유료 플랜이 필요합니다.)
- **로컬 파일**: `index.html`을 Chrome으로 바로 열어도 됩니다.
- **로컬 서버**: `python3 -m http.server 8000` 후 `http://localhost:8000`.

물리 엔진(MuJoCo WASM 약 11MB), three.js, ONNX Runtime Web은 jsdelivr CDN에서 받으므로 인터넷 연결이 필요합니다. claude.ai artifact 안에서는 보안 정책(외부 fetch 차단) 때문에 물리 엔진을 받을 수 없어 동작하지 않습니다.

| 설정 저장 | 브라우저 자동 저장, JSON 내보내기·가져오기 |

## 걷기 정책

걷기 정책 파일은 이 저장소에 포함하지 않았습니다. Open Duck Mini 프로젝트의 `BEST_WALK_ONNX_2.onnx`(입력 101 → 출력 14, 50Hz)를 받아 "걷기 정책 불러오기"로 올리거나 모델 zip 안에 같이 넣으면 자동으로 불러옵니다. 관측값 구성은 Open_Duck_Playground의 `mujoco_infer.py`를 그대로 따릅니다.

사전 테스트(평지, 8초) 결과: 전진 명령 0.15에서 약 0.09 m/s, 명령 0.3·걸음 주기 1.3배에서 약 0.18~0.22 m/s로 안정적이며, 명령 0.45 이상은 넘어집니다. 뛰기·점프는 이 정책으로 할 수 없고 새로 학습해야 합니다.

## 반복 실험 방법

- 첫 번째 지연 값이 기준 조건입니다.
- 같은 시드는 모든 지연 조건에서 같은 초기 관절 잡음(±0.01 rad)과 같은 외란을 받으므로, 시드끼리 짝지어 차이를 계산합니다.
- 신뢰구간은 시계열의 각 행이 아니라 **시드 단위로 재표본**한 bootstrap(2,000회) 95% 구간입니다.
- 실험은 화면의 시뮬레이션과 별도의 MjData에서 돌며, 실행 중에는 화면 시뮬레이션이 일시정지됩니다.

## 파일 구조

```
index.html          화면 구조와 로더(라이브러리 import 후 js 파일을 순서대로 실행)
css/style.css
js/core.js          공유 상태, 렌더러, 파일 불러오기, 모델 컴파일
js/scene.js         3D 장면, 근사 장식(서보·눈)
js/panel.js         액추에이터·센서 패널
js/timing.js        타이밍 주입 설정, 리셋
js/persona.js       성격·감정 레이어
js/policy.js        ONNX 걷기 정책
js/map.js           관제 테이블
js/diag.js          진단 모드
js/scenario.js      지형·외란
js/replay.js        리플레이
js/store.js         설정 저장, 파일 내려받기
js/experiment.js    반복 실험
js/sim.js           물리 스텝과 메인 루프
js/scope.js         타이밍 스코프와 지표
js/ui.js            이벤트 연결
js/main.js          시작
```

`js/` 파일은 ES 모듈이 아닌 클래식 스크립트로, 전역 상태를 공유합니다. 단일 HTML에서 분리하면서 동작을 바꾸지 않기 위한 선택이며, 이후 모듈화할 때는 공유 상태를 하나의 객체로 모으는 것부터 시작하면 됩니다.

## 한계

- 서보·눈 형상은 관절 위치 기반 근사입니다. 정확한 외형은 CAD에서 다시 변환해야 합니다.
- URDF는 직접 받지 않습니다(MJCF만).
- 계단 같은 형상 장애물은 MJCF에 직접 넣어야 합니다.
- 걷기 중 성격 반영은 머리 명령과 걸음 리듬으로 제한됩니다.

## 사용한 라이브러리

MuJoCo JavaScript 바인딩(Google DeepMind), three.js, ONNX Runtime Web, JSZip. 예제 로봇은 Open Duck Mini v2(apirrone)입니다.
